**Персонаж создан по мотивам рисунков художника Tikinson — [канал Tikinson Games в Telegram](https://t.me/tikinsongames).** Tikinson — это его ник, а сам персонаж — его автопортрет.

Русский · [English](README.en.md)

Живой питомец и приборная панель для Claude Code. **Tikinson** сидит в панели рядом с чатом и в реальном времени показывает, чем занят Claude: думает, работает, ждёт вас или уже закончил. Под ним — сколько израсходовано лимитов и контекста, а по желанию — подписка, нагрузка компьютера и список вызванных инструментов.

![Тикинсон: думает, работает, ждёт ответа, готово, ошибка](media/tikinson-states.gif)

## Для чего нужен Tikinson

- **Статус одним взглядом.** Claude часто работает минутами: читает файлы, запускает команды, правит код. Не нужно листать переписку: достаточно взглянуть на Тикинсона, чтобы понять, думает он, бежит выполнять команду или уже показывает «палец вверх».
- **Не пропустить момент, когда нужны вы.** Когда Claude задаёт вопрос или ждёт одобрения плана, Тикинсон разводит руками и звучит мягкий сигнал. Когда длинная задача готова — второй сигнал. Можно спокойно переключиться на другое окно.
- **Лимиты без сюрпризов.** Видно, какая доля пятичасового и недельного лимита уже использована и когда сброс. На 80% и 95% появляется предупреждение — лимит не закончится посреди задачи.
- **Контекст под контролем.** Шкала показывает, насколько заполнено окно контекста. Когда оно почти полное и Claude скоро начнёт забывать начало разговора, появляется кнопка «Сжать контекст».
- **Понятнее, что происходит.** Время хода и число вызовов инструментов — одной строкой, а в разделе «Инструменты» — что именно вызывалось, над чем и сколько длилось. Работа агента перестаёт быть «чёрным ящиком».
- **Компьютер в порядке?** Процессор, память и диск — в отдельном разделе. Полезно, когда Claude гоняет тяжёлые сборки и тесты на небольшой машине.
- **Интерфейс с характером.** Строгий инструмент разработчика становится чуточку теплее: у рабочего места появляется свой персонаж, а не только текст и спиннеры.
- **Образец для своих модов.** Компактный пример мода Claude Code: события хода, панель, состояние, SVG-анимация, фоновый процесс, звук, тесты. Его легко взять за основу для своего питомца или индикатора.

## Что в панели

Сверху вниз:

1. **Тикинсон** и его состояние: «Думает…», «Работает: Bash», «Готово!».
2. **Строка времени:** «3:44 · 8 вызовов инструментов», между ходами — «Последний ход 1:23 · …».
3. **Строка управления:** динамик 🔊 / 🔇 включает и выключает звуки, стрелка ︿ / ﹀ сворачивает всё, что ниже. Выбор запоминается между сессиями.
4. **Использовано лимитов** — три шкалы с процентом справа:
   - «Сессия · 5 ч» и время до сброса;
   - «Неделя» и дата сброса;
   - «Контекст» и число токенов. С 85% — кнопка «Сжать контекст».
5. **Раскрывающиеся разделы**, в начале каждой сессии закрыты:
   - **Компьютер** — процессор, память, диск; здесь же выключатель замеров;
   - **Подписка** — тариф, дата начала, оценка даты следующего списания, оплата сверх лимита;
   - **Инструменты** — последние вызовы хода: инструмент, над чем работал, длительность, ✓ или ✗.

Все числа живые: лимиты и контекст движок Claude Code присылает сам после каждого ответа, нагрузка компьютера обновляется раз в 5 секунд.

## Установка

В терминальной сессии Claude Code:

```
/plugin install tikinson-pet --marketplace Andryuha40/claude-pets
```

Ответьте `y` на вопрос о добавлении маркетплейса, затем выберите область (`user` — для всех сессий).

Из командной строки:

```bash
claude plugin install tikinson-pet --marketplace Andryuha40/claude-pets
```

В приложении Claude Desktop, где `/plugin` не работает: нажмите **+** рядом с полем ввода → **Plugins** → **Add marketplace** с `Andryuha40/claude-pets` → **Add plugin**.

Обновление с версии 0.1: переустановите плагин той же командой или обновите маркетплейс в `/plugin`.

## Использование

- Панель открывается сама при старте сессии. Если закрыли — команда `/tikinson`.
- Анимация и шкалы рисуются в Claude Desktop. В терминале вместо картинки — текстовый статус и обычные полосы прогресса.

## Требования и ограничения

- **Раздел «Компьютер» и звуки** рассчитаны на Windows: замеры читает встроенный PowerShell-скрипт `hooks/pcwatch.ps1`, звук играет системный проигрыватель Windows. На macOS звук играет движок Claude Code, а раздел «Компьютер» покажет «нет данных». Проверено только на Windows 10.
- **Лимиты** показываются только при входе по подписке Claude (Pro, Max, Team) и появляются после первого ответа в сессии.
- **Дата следующего списания — оценка**: следующее число месяца по дате начала подписки. При годовой оплате она будет неверной.
- **Значки на кнопках** — символы шрифта: API модов не позволяет класть в кнопку SVG и не даёт всплывающих подсказок.

## Токены и производительность

**Токены: расход не растёт.** Мод ничего не добавляет в системный промпт, не вызывает модель и не меняет результаты инструментов. Он только слушает события и рисует панель, а панель модель не видит. Единственное исключение — ручной запуск `/tikinson`: короткая строка попадает в историю (несколько токенов на запуск).

**Процессор: нагрузка почти нулевая.** Во время самой быстрой анимации все процессы Claude вместе — приложение, движок и панели — заняли **0,49% процессора** за 20 секунд (Windows 10, 12 потоков). Анимация идёт средствами SVG, таймер строки времени тикает раз в секунду и не перерисовывает остальную панель.

**Замеры компьютера** — один фоновый процесс PowerShell на сессию: около **1,4 с** процессора при запуске, дальше нагрузка ниже точности замера, и около **70 МБ** памяти. Выключатель в разделе «Компьютер» останавливает процесс и освобождает память; выбор запоминается.

**Звук:** около 0,3 с процессора на один сигнал, только в момент сигнала.

**Память мода:** около 0,6 МБ — кадры Тикинсона, встроенные в код.

## Конфиденциальность

- Мод ничего не отправляет в интернет.
- Из файла `~/.claude.json` читаются только поля тарифа: название плана, дата начала подписки, включена ли оплата сверх лимита. Почта, имя и ключи не читаются.
- В списке инструментов домашняя папка показывается как `~`.

## Как это устроено

Мод слушает события Claude Code: `turn.start`, `tool.call`, `turn.complete` (ход и инструменты), `session.measure` (лимиты и контекст), и хранит всё в состоянии сессии. Панель рисует кадры атласа Тикинсона в SVG с SMIL-анимацией.

| Файл | Что внутри |
| --- | --- |
| [`hooks/register.tsx`](hooks/register.tsx) | события, состояние, панель |
| [`hooks/timer.ts`](hooks/timer.ts) | строка времени, тикает сама |
| [`hooks/info.ts`](hooks/info.ts) | форматирование дат, чисел и подписей |
| [`hooks/pcwatch.ps1`](hooks/pcwatch.ps1) | замеры процессора, памяти и диска |
| [`hooks/pet.test.tsx`](hooks/pet.test.tsx) | тесты реакций и панели |
| `sounds/` | два мягких сигнала, синтезированы для этого мода |
