# Claude Pets · Tikinson

Русский · [English](README.en.md)

Живой питомец для Claude Code. **Tikinson** сидит в панели рядом с чатом и в реальном времени показывает, чем занят Claude: думает, работает, ждёт вас или уже закончил.

![Тикинсон: думает, работает, ждёт ответа, готово, ошибка](media/tikinson-states.gif)

## Зачем это нужно

- **Статус одним взглядом.** Claude часто работает минутами: читает файлы, запускает команды, правит код. Не нужно листать транскрипт: достаточно взглянуть на Тикинсона, чтобы понять, думает он, бежит выполнять команду или уже показывает «палец вверх».
- **Не пропустить момент, когда нужны вы.** Когда Claude задаёт вопрос или ждёт одобрения плана, Тикинсон разводит руками. Его видно краем глаза, даже если вы переключились на другое окно в том же приложении.
- **Понятнее, что происходит.** Под персонажем подписано, какой инструмент сейчас работает (Bash, Edit, Read…) и сколько вызовов было за ход. Работа агента перестаёт быть «чёрным ящиком».
- **Интерфейс с характером.** Строгий инструмент разработчика становится чуточку теплее: у рабочего пространства появляется свой персонаж, а не только текст и спиннеры.
- **Меньше нервов на длинных задачах.** Анимация сразу показывает, что работа идёт, а не зависла. Ошибку или прерывание тоже видно сразу: Тикинсон расстраивается.
- **Образец для своих модов.** Это компактный пример мода Claude Code: события хода, панель, состояние, SVG-анимация. Его легко взять за основу для своего питомца или индикатора.

## Как Тикинсон реагирует

| | Что делает Claude | Что делает Тикинсон |
| :---: | --- | --- |
| <img src="media/tikinson-think.gif" width="96" alt="думает"> | начал ход, думает над ответом | подпирает подбородок |
| <img src="media/tikinson-run.gif" width="96" alt="работает"> | вызывает инструмент | бежит, подпись — имя инструмента |
| <img src="media/tikinson-wait.gif" width="96" alt="ждёт"> | задаёт вам вопрос или показывает план | разводит руками |
| <img src="media/tikinson-done.gif" width="96" alt="готово"> | закончил ход | большой палец вверх, через 6 с — отдых |
| <img src="media/tikinson-fail.gif" width="96" alt="ошибка"> | ход прерван или ошибка API | расстраивается |
| <img src="media/tikinson-wave.gif" width="96" alt="привет"> | новая сессия | машет рукой |
| <img src="media/tikinson-idle.gif" width="96" alt="отдых"> | ничего не происходит | отдыхает |

Субагенты на питомца не влияют: пока работает субагент, Тикинсон «бежит» с подписью `Agent`.

## Установка

В терминальной сессии Claude Code:

```
/plugin install tikinson-pet --marketplace Andryuha40/claude-pets
```

Ответьте `y` на вопрос о добавлении маркетплейса, затем выберите область (`user` — для всех сессий).

Из командной строки:

```bash
claude plugin install tikinson-pet --marketplace Andryuha40/claude-pets
```

В приложении Claude Desktop, где `/plugin` не работает: нажмите **+** рядом с полем ввода → **Plugins** → **Add marketplace** с `Andryuha40/claude-pets` → **Add plugin**.

## Использование

- Панель открывается сама при старте сессии. Если закрыли — команда `/tikinson`.
- Анимация рисуется в Claude Desktop. В терминале вместо картинки показывается текстовый статус под полем ввода.

## Как это устроено

Мод слушает события Claude Code: `turn.start` (начало хода), `tool.call` (вызов инструмента), `turn.complete` (конец хода), и хранит текущее настроение в состоянии сессии. Панель рисует кадры атласа Тикинсона в SVG с SMIL-анимацией. Код — в [`hooks/register.tsx`](hooks/register.tsx), тесты реакций — в [`hooks/pet.test.tsx`](hooks/pet.test.tsx).
